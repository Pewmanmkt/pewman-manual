# Manual del sitio web · Pewman Innovation

Manual de autoadministración del sitio pewmaninnovation.net (Shopify) para el equipo de Pewman.

- `index.html`: el manual completo, en un solo archivo. Funciona en pantalla, con buscador, y se puede imprimir.
- Instrucciones verificadas contra el panel real de Shopify (agosto 2026).

## Publicación

Sitio estático: cualquier hosting lo sirve tal cual. Está desplegado en Vercel; cada push a `main` actualiza el sitio publicado.
